Documento con el código con el que se trabajó para entrenar un agente en base a reinforcement learning para aprender a ganar un juego de la librería `gymnasium`. El juego utilizado en este reporte fue `FrozenLake-v1`, en donde se cuenta con un lago congelado. Tiene pedazos de hielo en donde es seguro cruzar, además de agujeros que si cae ahí pierde y una meta a la cuál llegar para ganar. 


Se utiliza la tabla Q para que el agente vaya aprendiendo y mejorando. 


Al final, se crea un video con diferentes checkpoints (episodios) para ver el avance en aprendizaje del agente.
