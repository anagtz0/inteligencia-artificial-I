Este es un tutorial donde se hablan 2 métodos de clustering distintos (K-Means y Hierarchical). Se enseña al usuario cómo funcionan los distintos métodos, como crear código para replicarlos y las limitaciones.


Primero, se inicia con una base de datos sintética creada ahí misma en el código. Después, para el resto del tutorial se usa la base de datos NCI60 de la librería ISLP. La base de datos tiene 64 observaciones y 6830 variables. La variable objetivo son distintos tipos de cáncer. Se puede ver más información de la base de datos [aquí](https://islp.readthedocs.io/en/latest/datasets/NCI60.html).
